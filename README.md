# LENTO — 여유가 남는 향

HTML, CSS, JavaScript로 제작한 반응형 향수 브랜드 포트폴리오입니다.
별도의 npm 설치나 빌드 없이 실행할 수 있습니다.

## VS Code에서 실행하기

1. ZIP 파일의 압축을 풉니다.
2. VS Code에서 `파일 → 폴더 열기`로 `lento-vscode` 폴더를 엽니다.
3. 확장 프로그램에서 **Live Server (Ritwick Dey)**를 설치합니다.
4. `index.html` 파일을 우클릭하고 **Open with Live Server**를 선택합니다.
5. 브라우저의 `http://127.0.0.1:5500` 또는 `http://localhost:5500`에서 확인합니다. 포트 번호는 환경에 따라 달라질 수 있습니다.

가입과 로그인에 사용하는 브라우저 암호화 기능을 실행하려면 로컬 서버로 열어 주세요. 휴대폰에서 PC의 사설 IP로 접속하면 가입·로그인은 제한될 수 있으며, HTTPS 배포 주소에서는 사용할 수 있습니다.

## 수정할 파일

| 파일 | 수정 내용 |
| --- | --- |
| `index.html` | 페이지 구조, 제목, 본문, 메뉴 |
| `style.css` | 색상, 글꼴, 간격, 반응형 레이아웃 |
| `script.js` | 향 노트 탭, 용량 선택, 가격, 모바일 메뉴 |
| `fragrances.js` | 향수 4종 정보, 용량별 제품 이미지, 영상 선택 |
| `shop.js` | 회원가입, 간편가입, 로그인, 체험 주문, 주문 조회 |
| `shop.css` | 로그인·주문 화면 디자인 및 반응형 |
| `assets/` | 제품 사진, 영상 썸네일, MP4 영상 |

## 포함 기능

- 향수 4종과 향 노트 소개
- 30mL·50mL 선택에 따른 사진 및 가격 변경
- 향 설명을 표현한 풍경 영상 4종
- 일반 회원가입과 로그인
- 체험 계정을 발급하는 간편가입
- 회원·비회원 체험 주문 및 주문 조회
- 데스크톱·태블릿·모바일 반응형

## 체험 주문 사용법

1. 상품의 향과 용량을 선택하고 **구매하기**를 누릅니다.
2. 예시 이메일로 비회원 주문을 접수하거나 로그인 후 회원 주문을 접수합니다.
3. 완료 화면의 주문번호를 기록합니다.
4. 상단 **주문 조회**에서 주문번호와 이메일을 입력합니다.
5. 회원 주문은 **내 계정**에서도 확인할 수 있습니다.

## 저장 및 서비스 범위

가상의 브랜드를 구현한 포트폴리오용 프로젝트입니다. 계정과 주문은 같은 브라우저의 저장소에 보관되며 실제 결제나 배송은 진행되지 않습니다. 일반 가입에는 예시 이메일과 체험용 비밀번호를 사용하세요.

간편가입은 카카오·네이버·Google 계정 연동이 아니라 체험용 이메일과 비밀번호를 발급하는 방식입니다. 발급 화면에서 정보를 복사해 두면 다시 로그인할 수 있습니다.

배포 사이트와 로컬 서버는 서로 다른 저장소를 사용합니다. 같은 PC에서도 접속 주소나 포트가 바뀌면 저장된 계정과 주문이 별도로 관리됩니다. 기존 저장 내용과 호환되도록 내부 저장 키에는 이전 브랜드 이름이 남아 있습니다.

글꼴은 Google Fonts에서 불러오므로 인터넷 연결이 필요합니다. 제품 사진과 영상은 `assets` 폴더에 포함되어 있습니다.
