
# ELUNE — DAILY NICHE PERFUME

은은한 존재감, 오래도록 남는 향.
ELUNE은 일상의 순간과 감정을 향으로 표현하는 가상의 니치 퍼퓸 브랜드입니다.
깨끗함과 포근함, 섬세한 분위기를 중심으로 브랜드 아이덴티티를 구축하고, 제품 소개부터 향의 스토리까지 하나의 흐름으로 경험할 수 있도록 제작한 반응형 웹 포트폴리오입니다.

## Project Features

- 브랜드 콘셉트를 표현한 메인 비주얼과 자동 슬라이드
- 4종 향수 컬렉션 및 제품 상세 정보
- 30mL / 50mL 용량 선택과 제품 이미지 변경
- Top / Middle / Base 향 노트 소개
- 향수별 콘셉트를 표현한 영상 콘텐츠
- 회원가입 및 로그인 UI
- 장바구니 및 체험 주문 기능
- 섹션별 이동 내비게이션
- 데스크톱, 태블릿, 모바일 반응형 레이아웃

## Getting Started

### 1. 저장소 복제

```bash
git clone https://github.com/2seula-a/elune.git
```

### 2. 프로젝트 폴더 이동

```bash
cd elune
```

### 3. 패키지 설치

```bash
npm install
```

### 4. 개발 서버 실행

```bash
npm run dev
```

터미널에 표시되는 로컬 주소로 접속하여 확인합니다.

## Build & Deploy

프로덕션 빌드:

```bash
npm run build
```

GitHub Pages 배포:

```bash
npm run deploy
```

Vite의 `base` 경로는 `/elune/`으로 설정되어 있습니다.

## Project Notes

본 프로젝트는 웹 디자인 및 프론트엔드 구현을 목적으로 제작한 개인 포트폴리오입니다.
ELUNE은 가상의 향수 브랜드이며, 실제 상품 판매 및 결제 서비스를 제공하지 않습니다.
브랜드 콘셉트, 제품 비주얼, 영상 콘텐츠, 반응형 UI 및 인터랙션 구현을 중심으로 구성했습니다.
